### 🚀 Featured Projects

#### 1. [DetactiveAR (Dedektif Pati)](https://github.com/Adil-Can-Kural/DetactiveAR) — *Offline AR Edutainment App*
A 100% offline Augmented Reality detective game designed specifically for children aged 6–9 to play in constrained spaces like airplane tray tables.
* **Product & UX Focus:** Replaced physical room-scale movement with intuitive on-screen virtual navigation and crafted child-friendly guidance.
* **Deliverables:** Shipped a playable Android release (`v1.0 APK`), gameplay/presentation videos, and full bilingual documentation (`English` & `Turkish`).
* **Tech Stack:** Unity, C#, AR Foundation (ARCore / ARKit), TextMeshPro.

#### 2. [DuyguTanima](https://github.com/Adil-Can-Kural/DuyguTanima) — *Multi-Task Speech Emotion & Intensity Recognition*
A deep learning pipeline predicting both emotional state (8 classes) and emotional intensity (`normal` vs. `strong`) from speech audio.
* **Experimentation & Evaluation:** Analyzed 1,440 RAVDESS audio samples using sliding-window segmentation (`50-frame` windows, `25-frame` step) and `13 MFCC` features to test how temporal context impacts model consistency.
* **Optimization:** Built a dual-output Bidirectional LSTM architecture and diagnosed validation divergence using `EarlyStopping` and learning rate scheduling.
* **Tech Stack:** Python, TensorFlow / Keras, Librosa, Scikit-learn, Pandas, NumPy.
